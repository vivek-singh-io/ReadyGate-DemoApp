# 🎟️ ReadyGate Demo Application

A fictional **ticket-management application** created as an external repository fixture for the **ReadyGate Hackathon Demo**.

> ⚠️ **Demo / Fixture Repository**
>
> This project is intentionally designed for demonstration purposes and is **not production software**. Some implementation gaps are deliberate and are used to showcase ReadyGate's **Block, Conditional, and Pass** flows.
>
> Do not use the intentional fixture gaps or implementation patterns in this repository as production guidance.

## 🛠️ Technology Stack

* **Frontend:** Angular
* **Backend:** .NET
* **Data:** SQLite / in-memory test data

## 🎯 Purpose

The application provides a lightweight ticket-management scenario for demonstrating ReadyGate's policy and workflow capabilities.

The repository intentionally includes several implementation gaps so that different ReadyGate outcomes can be demonstrated:

| Flow               | Purpose                                                    |
| ------------------ | ---------------------------------------------------------- |
| 🛑 **Block**       | Demonstrates when an action should be prevented            |
| 🔀 **Conditional** | Demonstrates when an action requires additional conditions |
| ✅ **Pass**         | Demonstrates when an action is allowed to proceed          |

## 📁 Project Structure

The repository contains the components required to run the demo application, including:

* Angular frontend
* .NET backend services
* SQLite / in-memory test data
* Intentional fixture scenarios for ReadyGate demonstrations
